# Documentation

This folder contains supporting documentation for the bachelor's thesis replication package.

The purpose of these documents is to explain the empirical workflow, describe the datasets, and provide guidance for reproducing the analysis.

## Contents

| File | Description |
|------|-------------|
| methodology.md | Overview of the empirical methodology and modelling strategy |
| data_dictionary.md | Description of all datasets and variables used |
| replication_guide.md | Step-by-step instructions for reproducing the analysis |
